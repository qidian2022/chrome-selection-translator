划词译 / OPENAI

读到哪里，译到哪里。

选中文字，点击浮条上的「翻译」，中文译文就在旁边。

填入你自己的 API 密钥。

默认 gpt-6-luna，关闭推理、直接翻译；也可以填写你账户可用的文本模型名称。

也可使用右键菜单，或快捷键 Option/Alt + Shift + T。

密钥保存在本机 Chrome 扩展存储中，不随 Chrome 账户同步；本机存储未加密。首次翻译或重新翻译时，所选文字会发送至 OpenAI 官方接口。已完成的译文在内存中短时缓存，便于重复查看。测试按钮会发送一句示例英文，按你的 API 账户计费。
